# 8月兼职表现总结 · 设计宪法

## 1. 画布与母版

- **画布**：1280 × 720 px（16:9）
- **三区方案**（内容页：P02、P04、P05、P06、P08、P09）：
  - **A 标题块**：y 0–120px（高 120px，含上 padding 20），主标题 32–40px bold，主色 `#3E2F23`
  - **B 内容区**：y 120–660px（高 540px），padding 左右 60px
  - **C 页脚条**：y 660–720px（高 60px，含下 padding 20），左侧 14px 灰字项目名 "安福路 Salomon 兼职管理"，右下页码 `NN / 10`
- **封面（P01）/ 章节扉页（P03、P07）/ 结束页（P10）**：自定义版式，可省略 C 区，标题允许更大（封面 60-96px）
- **角标（L3）**：全篇统一位置 = 页脚条 C 区右下页码左侧 12px 处，固定一个 SALOMON ANFULU 文字角标（14px 主色 alpha 0.6）

## 2. 颜色系统

### 2.1 主色板（4 hex，符合"≤4 主色"硬约束）

| 角色 | hex | 名称 | 用途 |
|---|---|---|---|
| **Primary · 主色** | `#3E2F23` | 深咖棕 | 标题、主背景叠加层、图表主色 |
| **Secondary · 辅色** | `#C08A5E` | 驼金 | 卡片底色、图表第二系列、分隔强调 |
| **Accent · 强调** | `#D65A3F` | 陶土红 | 锚点数字描边、TOP 排名高亮、关键洞察框 |
| **Background · 背景** | `#F5EFE6` | 暖砂 | 全篇主背景 |

### 2.2 中性 / 文本（不计入主色预算）

- 文本主色：`#241C16`（近黑棕，替代纯黑以维持暖调）
- 文本次色：`#6B5B4B`（灰褐，次要注释 / 页脚）
- 反白：`#FFFFFF`
- 浅底：`#E8DCC9`（暖砂加深 8%，用于斑马纹 / 卡片次层）

### 2.3 色彩面积分配

| 角色 | Hero 页 | Supporting 页 |
|---|---|---|
| 主色 | 30-40% | 45-55% |
| 辅色 | 30-45% | 25-30% |
| 强调色 | **15-20%**（允许爆发） | **≤5%** |
| 背景 | 20-25% | 25-30% |

- 至少 2 页的色彩比例与其他页显著不同：P04 强调色爆发 20%；P08 主色主导 50%（其他页都在 40-50%）
- 禁止同一页面出现 ≥ 2 套主色板（本项目就是一套）

### 2.4 渐变与半透明

- **左骑线色块**（封面）：`background: 'linear-gradient(90deg, rgba(62,47,35,0.78) 0%, rgba(62,47,35,0.45) 70%, transparent 100%)'`
- **章节扉页蒙版**：`background: 'rgba(62,47,35,0.45)'` 覆盖 L1 主图
- **结束页蒙版**：`background: 'rgba(62,47,35,0.55)'` 覆盖复用 cover 图
- **图表卡片浮起**：`boxShadow: '0 4px 16px rgba(62,47,35,0.10)'`

### 3.2 字体家族（≤2 套）

- **Family A（中文 + 默认）**：`'PingFang SC', 'Microsoft YaHei', 'Hiragino Sans GB', sans-serif`
  - 用于全部中文文本、卡片标题、正文
- **Family B（数字 + 大字标题）**：`'Arial', 'Helvetica Neue', sans-serif`
  - 用于巨型数字 ¥67,532、章节编号 "01"/"02"、指标卡数字 12032 之类
- 标题与正文允许同族（Family A），但通过 fontSize/weight 对比拉开层次

## 4. 信息密度门禁

- **常规内容页留白**：≤ 35%（Hero 页允许达 40-50%）
- **单主题内容页字数**：≥ 180（P04 200 / P05 240 / P06 230 / P08 260 / P09 300）
- **每个视觉锚点周围**：≥ 40px 呼吸空间
- **卡片填充率**：≥ 85%
- **底栏锚定**：卡片末尾的"标签条 / 行动按钮"用 `marginTop: 'auto'`

## 7. 全篇硬约束

- 母版区严格：A 标题块 0-120 / B 内容区 120-660 / C 页脚条 660-720
- 仅使用上面 4 主色 hex + 3 中性色（不超过 7 色，含中性）
- 仅使用 2 套字体家族
- 标题块右侧不得塞 200×70 装饰小图
- 与上一页版式不重复
- 本页有 ≥ 1 个 ≥ 44px 元素 或 ≥ 40% B 区面积的主图
- 本页与上一页视觉重量有显著差异（最大元素面积比 > 1.5:1 或版式结构明显不同）
- 本页色彩分配符合 DESIGN.md 页面映射表
- 本页 role 与 STORY.md 一致：hero 页必须有 ≥ 40% B 区主视觉或 ≥ 48px 锚点数字
