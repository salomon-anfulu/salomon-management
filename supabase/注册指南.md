# Supabase 注册 + 建表操作指南

## 第一步：注册 Supabase 账号（5 分钟）

1. 打开 https://supabase.com
2. 点击右上角 **"Start your project"**
3. 选择 **"Sign in with GitHub"**（最快，直接用你的 GitHub 账号）
4. 授权后进入 Dashboard

> 如果不想用 GitHub 登录，也可以用邮箱注册，但 GitHub 登录最省事。

---

## 第二步：创建新项目（2 分钟）

1. 点击 **"New project"**
2. 填写项目信息：
   - **Name**: `salomon-parttime`（随便起，自己认得就行）
   - **Database Password**: 点 **"Generate a password"** 自动生成，**复制保存到备忘录**（很重要！丢了只能重置数据库）
   - **Region**: 选 **`Southeast Asia (Singapore)`**（离中国最近，延迟最低）
   - **Pricing Plan**: 选 **Free**（免费档完全够用）
3. 点 **"Create new project"**
4. 等待 1-2 分钟，项目创建完成后会自动进入 Dashboard

---

## 第三步：执行建表 SQL（3 分钟）

1. 在左侧导航栏点 **"SQL Editor"**（有个 `>_` 图标）
2. 点 **"New query"**
3. 用文本编辑器打开项目目录下的 `supabase/schema.sql`
4. **全选复制**，粘贴到 SQL Editor 的输入框
5. 点右下角 **"Run"** 按钮（绿色播放按钮）
6. 等待执行完成，底部会显示 `Success. No rows returned.`
7. 如果看到红色错误，截图发我

### 验证建表成功

再开一个 New Query，粘贴执行：

```sql
SELECT tablename FROM pg_tables WHERE schemaname = 'public' ORDER BY tablename;
```

## 第四步：获取 API 密钥（2 分钟）

这是前端代码连接数据库需要的"钥匙"。

1. 在左侧导航栏点 **"Project Settings"**（齿轮图标）
2. 点 **"API"**
3. 找到以下两个值，**记录下来**（稍后要写入代码）：

| 名称 | 说明 | 示例 |
|------|------|------|
| **Project URL** | 数据库地址 | `https://xxxxxxxxxxxx.supabase.co` |
| **anon public key** | 公开密钥（前端用，RLS 保护安全） | `eyJhbGciOi...`（很长一串） |

> **注意**：anon key 是公开的，设计上就是放在前端代码里的。安全靠 RLS 策略保证，不靠 key 保密。但 **service_role key 绝对不能放前端**，那个是管理员权限，只能在服务端用（目前你不需要）。

## 第五步：验证一切正常

### 方法 A：在 Supabase 控制台手动插入一条测试数据

1. 左侧点 **"Table Editor"**
2. 点 **"staff"** 表
3. 点 **"Insert row"**
4. 填入测试数据：
   - `name`: 测试员
   - `dept`: Service Team
   - `status`: active
5. 点 **"Save"**
6. 再回到 SQL Editor 执行 `SELECT * FROM staff;`，应该看到这条记录

### 方法 B：直接在 SQL Editor 插入

```sql
INSERT INTO staff (name, dept, status, avatar_color)
VALUES ('测试员', 'Service Team', 'active', '#3b82f6');

SELECT * FROM staff;
```

## 常见问题

### Q: 执行 SQL 报错怎么办？
A: 截图发给我，我看报错信息帮你修。常见原因：
- 语法错误（不太可能，已经测过）
- 表已存在（如果你重复执行，加 `IF NOT EXISTS` 已处理）
- 权限不足（免费档不会有这问题）

### Q: 免费档有什么限制？
A: 对你完全没影响：
- 500MB 存储（你的数据不到 5MB）
- 50 万次/月读写（20 人每天填报约 500 次，一个月 1.5 万次）
- 50000 并发连接（你最多 20 人同时在线）
- 数据库暂停：**免费档 7 天不活动会暂停**，但只要有人访问就自动唤醒，不会丢数据

### Q: 数据安全吗？会不会丢？
A: Supabase 每天自动备份，可以随时恢复到任意时间点。比你现在 GitHub 单文件安全得多。

### Q: 以后不想用了怎么办？
A: Project Settings → General → Delete Project，数据导出后再删。也可以随时暂停（免费档 7 天无访问自动暂停）。
